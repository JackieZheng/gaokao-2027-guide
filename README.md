# 2027 高考志愿填报指南

一份面向**高中生家长与学生**的方法论手册，覆盖政策全景、位次与梯度、志愿填报策略、专业与院校选择、身体条件与特殊通道、风险防控等 8 大板块。

## 关于本手册

本指南由雪人老师整理，是"家长与学生都能看懂"的方法论整理，而非替你做决定的答案手册。填报过程中，请结合孩子本人的兴趣、特长、身体条件与家庭实际，并始终以"省教育考试院"当年官方公告为最终依据。
